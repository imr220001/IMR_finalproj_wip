# Gryphon Generator Proposal

## Repository
https://github.com/imr220001/IMR_finalproj_wip.git

## Description
This project will help randomly generate a unique gryphon mixture. This will assist in brainstorming creature design variations for concept art. I've seen a couple 'random hybrid generators' floating around for art trends but not one for gryphons specifically, and I think it would be interesting. 
## Features
- Pick halves
	- using libraries listing types of avian and types of feline, pick and display a randomly selected bird and feline to make the front and back halves of a gryphon. 
- Toggle bonus features
	- program will have x number of extra traits it can roll for. This feature will allow users to toggle how many extra features they want to roll for. 
- Bonus Traits
	- Series of bonus traits that can be added (external ears True/False, flipped halves, tail feline/avian/both, size based on bird or cat half, mutations(piebald, melanistic, albino, polydactyly, etc.). Each feature has an on/off toggle and mutations feature lets users choose how many to generate).
- Proper Display of data
    - format and display the results legibly (if possible, display picture examples?)
